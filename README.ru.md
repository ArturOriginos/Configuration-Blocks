# Configuration Blocks

[English](README.md) | **Русский**

**NeoForge 1.21.1** · MIT

Мод добавляет один предмет — **Конфигуратор** (бумага). Им можно настроить почти любую характеристику уже поставленного блока, не меняя сам блок.

*English: adds a single item, the **Configurator** (a paper). Right-click any placed block to change its properties: hardness, blast resistance, gravity, light, redstone power, bounciness and block functions (chest, furnace, crafting table, jukebox, ...).*

## Как пользоваться

* **Крафт:** бумага + редстоун + светокаменная пыль + железный слиток (бесформенный). Также есть в творческой вкладке «Инструменты».
* **ПКМ по блоку** с Конфигуратором в руке — открывается окно настроек.
* **Shift + ПКМ** — сбросить все настройки блока.

## Что можно настроить

| Параметр | Что делает |
|---|---|
| Прочность | Скорость добычи. `-1` — неразрушимый (как бедрок). Пусто — по умолчанию |
| Взрывоустойчивость | `17` и выше — блок не разрушается взрывами; ниже — пропорциональный шанс уцелеть |
| Свечение 0–15 | Свет вокруг блока (через невидимые блоки `minecraft:light` в соседнем воздухе) |
| Редстоун-сигнал 0–15 | Блок излучает редстоун-сигнал |
| Прыгучесть | Блок работает как батут, отменяет урон от падения (Shift — не прыгать) |
| Физика | Блок падает как песок; при приземлении настройки и содержимое переезжают вместе с ним |
| Настройки хранилищ | Для сундука / шалкера: **ряды** (1–6, только сундук), **лимит предметов в слоте** (1–99; нестакуемые остаются по 1) и **замок** (открывать, менять и ломать может только владелец или оператор; печки тоже можно запереть) |
| Рисование | Кнопка **«Рисовать...»** открывает редактор 16×16 пикселей для грани, по которой вы кликнули (грани переключаются внутри редактора). Инструменты: карандаш, ластик, заливка, пипетка, отмена; 16 цветов красителей и любой `#RRGGBB`; ПКМ стирает. Оригинальная текстура видна под рисунком, нетронутые пиксели остаются ванильными |
| Функция | Сундук (27 слотов, содержимое сохраняется), эндер-сундук, верстак, печка, плавильная печь, коптильня, наковальня, стол зачарований, кузнечный стол, точило, ткацкий станок, картографический стол, камнерез, проигрыватель (ПКМ с пластинкой), **шалкер** (27 слотов), **спавнер** (спавнит выбранного моба по id, например `minecraft:zombie`) |

Настройки привязаны к **конкретному блоку в мире** и хранятся в данных измерения. Если блок сломан или заменён другим — настройки исчезают, содержимое выпадает.

## Ограничения

* Работает с поставленными блоками, а не со всем типом блока сразу.
* Блоки с собственным блок-энтити (настоящие сундуки и т. п.) не могут падать (физика).
* Блок, сдвинутый поршнем, теряет настройки.
* Взрывоустойчивость может только *повышать* защиту; сделать бедрок взрываемым нельзя.
* Строгое сходство «редстоун-источника» для соединения проводов визуально не меняется.
* Рисунок рисуется поверх блока как накладка, поэтому лучше всего подходит полным кубам (у ступенек, плит и растений картинка будет на грани полного куба). Грани, закрытые соседними блоками, не рисуются; видимость рисунков — 128 блоков.
* Мод нужен и на клиенте, и на сервере. Используется 1 миксин (`BlockStateBase`).
